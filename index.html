使用指南与验收清单

运行说明

  1. 直接双击项目目录中的 index.html，即可在浏览器使用。
  2. 也可在该目录运行 python -m http.server 8080，再访问 http://localhost:8080；使用本地服务更利于开启系统通知。
  3. 在“项目规划”中可导入 XLSX / CSV / TSV，或直接粘贴 Excel 单元格；旧版 XLS 请先另存为 XLSX / CSV。
  4. 在“AI 拆解”中直接输入规划或上传任务表，生成预览后点“加入工作台”；默认使用本地规则，可在“模型设置”里接入自己的模型接口。
  5. 数据默认写入当前浏览器的 localStorage；清除浏览器数据前请先导出 JSON 备份。品牌已统一为“三院”，旧数据会自动迁移，不会丢失。
